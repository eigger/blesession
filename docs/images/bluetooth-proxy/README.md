# Bluetooth proxy installation screenshots

Source: the user-supplied PDF of 블루투스 프록시 설치하기, by 취밍, published 2026-11-12. These are article examples, not captures of the user's installation. Comments are not used.

The embedded source images were extracted directly, rather than capturing a PDF page. Dialogs were cropped, surrounding page fragments removed and corners made transparent. Text, buttons and progress values were preserved. Both language guides reuse these assets.
